# Подпись

Браузерная игра, в которой нужно придумать смешную подпись к фото за 50 символов. LM Studio оценивает ответы на твоём ПК. Можно играть одному или компанией из 2–5 человек.

## Запуск на Windows

1. Установи [Node.js 22+](https://nodejs.org/) и [LM Studio](https://lmstudio.ai/). В LM Studio загрузи модель с поддержкой изображений, например Qwen3-VL-8B-Instruct, и запусти сервер.
2. Запусти `start.cmd` или выполни `npm start`. Игра доступна на [localhost:8765](http://127.0.0.1:8765).
3. Подключи LM Studio, выбери модель и сохрани настройки. Адрес по умолчанию — `http://127.0.0.1:1234/v1`.

Фоновый запуск останавливается через `stop.cmd`.

## Игра с друзьями

Установи [Tuna CLI](https://tuna.am/docs/guides/install/install-cli/) или положи `tuna.exe` из официального архива в папку `bin`. Один раз запусти `setup-tuna.cmd` для входа. Затем запусти `start-online.cmd`, нажми **Играть компанией** и скопируй приглашение. Пока идёт игра, ПК, LM Studio и туннель должны работать.

## Данные и тесты

Настройки, подписи и оценки хранятся в `data/`. Фотографии раундов остаются в памяти до закрытия игры или комнаты.
